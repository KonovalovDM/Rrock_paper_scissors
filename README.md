# Камень, ножницы, бумага

Простая консольная игра \"Камень, ножницы, бумага\".
Игрок соревнуется с компьютером.

## Правила
- Камень побеждает ножницы
- Ножницы побеждают бумагу
- Бумага побеждает камень

## Запуск
\`\`\`bash
python game.py
\`\`\`
