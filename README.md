# 🎮 Игра "Камень-Ножницы-Бумага"

## 📖 Описание

Простая консольная игра "Камень, ножницы, бумага", реализованная на Python. Игрок соревнуется с компьютером, выбирая один из трёх вариантов. Результаты сохраняются в файл для анализа.

## 🎯 Как играть

Правила игры
Выберите один из вариантов:

камень — побеждает ножницы
ножницы — побеждают бумагу
бумага — побеждает камень

Компьютер делает случайный выбор
Определяется победитель раунда
Счёт обновляется
Можно продолжать или завершить игру

Управление
Введите камень, ножницы или бумага для хода
Введите exit или выход для выхода из игры
После каждого раунда можно выбрать: продолжать или нет
